# F17 demonstration dataset for ViroXplore-HPC

This example uses a downsampled F17 dataset derived from the published freshwater-fish virus discovery study by Hierweger et al. (2021): *Novel Filoviruses, Hantavirus, and Rhabdovirus in Freshwater Fish, Switzerland, 2017*. *Emerging Infectious Diseases* 27:3082–3091. DOI: https://doi.org/10.3201/eid2712.210491; PMID 34808081; PMCID PMC8632185.

The contributing researcher provided the exact subset used during ViroXplore-HPC development. It contains **1,000,000 paired-end read pairs**, i.e., 1,000,000 R1 reads and 1,000,000 R2 reads (2,000,000 individual reads). These are **raw sequencing reads with no prior host-read removal**. The original downsampling commands and seed are not available; this exact subset is therefore identified by its cryptographic file checksums rather than by a reproducible sampling recipe. The contributor confirms that these data may be redistributed.

## SE test construction

The SE test is **not an independently generated single-end sequencing library**. It contains all R1 records followed by all R2 records. It was generated by concatenating the two gzipped input files without re-compression, yielding a valid concatenated-member gzip stream:

```bash
bash examples/F17/generate_SE_from_PE.sh F17_RNA_1Mio_R1.fastq.gz F17_RNA_1Mio_R2.fastq.gz F17_RNA_1Mio_SE.fastq.gz
sha256sum -c examples/F17/checksums.sha256
```

Some gzip readers do not support concatenated members. In that case, decompress and recompress to a single gzip member, keeping in mind that the compressed-file checksum will change.

## Using the reads with the pipeline

- For PE analysis, place the two files under the configured `reads/` directory, keeping the `_R1.fastq.gz` and `_R2.fastq.gz` suffixes. Select `SEQUENCING_MODE=PE`.
- For SE analysis, select `SEQUENCING_MODE=SE` and stage the derived SE file under a **distinct sample prefix ending in `_R1.fastq.gz`**, e.g. `reads/F17_SE_R1.fastq.gz`, to meet the current configurator's expected filename convention. Do not place the unrelated R2 file under the same SE sample prefix.
- Consult `docs/INSTALLATION.md` for configuration, STAR host-reference generation, local databases, and SLURM submission.
- Original tested `fastp` parameters were configured for Lexogen CORALL total RNA libraries; these have not been altered for this public example.

## Expected outputs and interpretation

See `expected_results.tsv` for selected counts from the previous v1.0.0 validation on the IBU HPC cluster. These counts depend on the *same container, host reference, RefSeq and DIAMOND database snapshots, filtering rules, and pipeline configuration*; they must not be interpreted as universal expectations for updated reference databases. The PE and PE-derived SE analyses are **technical workflow checks**, not independent biological replicates or estimates of diagnostic sensitivity or specificity.

The original raw reads and reference databases are **not bundled in the software v1.0.0 release**. The v1.0.0 tag and its original Zenodo software archive remain unchanged.
