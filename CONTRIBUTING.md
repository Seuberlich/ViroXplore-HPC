# Contributing

Please open a GitHub issue before proposing substantial changes. Separate environment/packaging changes from scientific algorithm changes. For code changes, include PE and SE tests whenever applicable and document database versions needed to reproduce the result.

Do not share raw clinical reads or private HPC credentials in issues or pull requests. Contributions to this repository are proposed under the BSD-3-Clause license. See `LICENSE`, `AUTHORS.md` and `docs/PRE_PUBLICATION_CHECKLIST.md` for credit and remaining provenance checks.
